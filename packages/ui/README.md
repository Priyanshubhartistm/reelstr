# @reelstr/ui

Shared React UI and the Pine and Cream design system: sign-in gate and session, wallet and payments provider, HLS player, story tree, split table, app shell, router, and `theme.css`. The design notes are in [`docs/DESIGN-SYSTEM.md`](../../docs/DESIGN-SYSTEM.md).

**Main exports:** `LoginGate`, `useSession`, `PaymentsProvider`, `HlsPlayer`, `AppShell`, `useRoute`, `Wallet`.

**Test:** `bun run test (type-checked through the web app and the browser tests)`.
