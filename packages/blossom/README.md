# @reelstr/blossom

Client for Blossom media servers (BUD-01, 02, 04, 11): authorised uploads, mirroring, and fetches that verify the SHA-256 of what they receive.

**Main exports:** `BlossomClient`, `uploadAndMirror`, `fetchVerified`, `authHeader`, `installUrlRewrite`.

**Test:** `bun test packages/blossom`.
