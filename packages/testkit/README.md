# @reelstr/testkit

Helpers for the test suites: start a relay, crew relay, Blossom server, Cashu mint or Lightning node; temporary directories and free ports; in-process doubles for fast unit tests.

**Main exports:** `startRelay`, `startBlossom`, `startNutshell`, `startLndRegtest`, `startNakBunker`, `tempDir`.

**Test:** `bun test packages/testkit`.
