# @reelstr/wallet

The money side of the client: a Cashu wallet, NIP-60 token storage on relays, NIP-61 nutzaps, NWC (NIP-47) connections, zap-split tips, and the flows that unlock an episode or pay an agent.

**Main exports:** `CashuWallet`, `Nip60Store`, `unlockWithNutzap`, `unlockWithLightning`, `zapSplit`, `NwcWallet`, `requestJob`.

**Test:** `bun test packages/wallet`.
