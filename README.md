# Reelstr

Open-source Pocket FM on Nostr: forkable 10-15 s AI scenes, curator-assembled 60-120 s episodes, per-episode sats with splits declared in signed events.

- `docs/research.md`: market and feasibility research (2026-09-30)
- `docs/DEVIATIONS.md`: where the build differs from the PRD, and why
- `docs/nip/reelstr.md`: protocol draft (kinds, tags, split rules)

```sh
bun install
bun run check   # biome + tsc + tests
```
